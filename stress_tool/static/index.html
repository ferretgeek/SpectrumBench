三个速度数字，回答三个不同问题

01 / 速度可见文本速度

主测速指标。以首个可见文本事件为起点，计算后续可见 token 的生成速率，避免首块整体到达造成虚高。

02 / 体验端到端可见吞吐

可见 token 除以请求开始到最后可见事件的时长，更接近真实等待体验，会受到首字延迟与推理强度影响。

03 / 额度额度消耗速率

全部输出 token 除以完整请求时长，包含隐藏推理，只用于观察额度消耗，不能当作可见生成速度。

历史样本对比

只在统计口径满足可比条件时发布倍率。

速度倍率要求同模型、同场景版本、同推理等级且质量门禁通过；额度倍率可跨模式，但双方都必须确认撞限额。
